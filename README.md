# Rampage shop: поиск и каталог

Открой index.html в браузере. Сборка, сервер, npm и интернет для поиска и картинок не нужны.

## Что добавлено

Карточки записаны прямо в index.html, как в исходном примере. JavaScript не создаёт HTML и ничего не скачивает при открытии страницы.

В каталоге 246 карточек: 73 базовых предмета, 114 улучшенных, 49 нейтральных предметов по уровням и 10 наград/собираемых предметов. Это снимок каталога на 4 ноября 2026 года. Рецепты, отдельные нейтральные зачарования, удалённые и невыпущенные предметы не включены. Улучшенные версии Dagon и Boots of Travel перечислены отдельно.

Для всех 246 карточек сгенерированы отдельные иллюстрации объявлений: предметы на столе или прилавке, как будто герой сфотографировал их перед продажей. Все новые изображения подключены из img/marketplace. Исходные игровые иконки сохранены в img/items как референсы. Статус и точные промпты по каждому предмету находятся в work/image-jobs.json. Использован встроенный imagegen. More открывает страницу предмета в англоязычной Liquipedia; некоторые названия могут перенаправляться на основную статью. Ссылки вики требуют интернета.

Остальные страницы проекта оставлены пустыми, как в исходном проекте. Дизайн и сетка не добавлялись. В style.css только скрытие отфильтрованных элементов, сохранение пропорций картинок и выравнивание значка золота.

## Как работает поиск

В script.js сначала находятся поля и карточки через document.querySelector и document.querySelectorAll.

filterItems() читает текст из поля. trim() убирает пробелы по краям, toLowerCase() приводит текст к нижнему регистру. Поэтому `  BLINK  ` находит Blink Dagger и улучшенные Blink. includes() проверяет вхождение строки, а не только точное совпадение.

forEach проходит по каждой карточке. Для неё проверяются три условия: название, категория, тег. Между условиями стоит && — должны совпасть все три.

Если карточка не подходит, card.hidden становится true. Атрибут hidden скрывает элемент. В style.css есть [hidden] с display: none !important, чтобы будущее оформление карточек через display: flex или grid не мешало фильтру.

После этого функция скрывает секции без результатов, обновляет счётчик и показывает сообщение, если ничего не найдено.

## Как устроены фильтры

Данные находятся в HTML-атрибутах карточки:

```html
<div class="blink-dagger item-card"
     data-name="Blink Dagger"
     data-category="miscellaneous"
     data-group="basic-items"
     data-tags="teleport mobility escape">
```

- item-card — общий класс, по которому JavaScript находит все товары.
- blink-dagger — индивидуальный класс для твоего CSS.
- data-name — название для поиска. Если меняешь заголовок, поменяй и это значение.
- data-category — категория, например equipment, consumables или magical.
- data-group — большой раздел: basic-items, upgraded-items, neutral-items или other-items.
- data-tags — игровые теги через пробел. Теги взяты из ItemShopTags игровых данных. Это классификация разработчиков игры, а не полный перечень всех эффектов предмета.

В JavaScript data-category читается как card.dataset.category. Значение option в select должно совпадать с data-category либо data-group. Значение тегового option должно совпадать с одним из слов data-tags.

Выбор All items или All tags отключает соответствующее ограничение. Категория и тег выбираются по одному; поиск, категория и тег работают одновременно.

## События

- input у поля поиска — обновляет результаты при вводе и очистке.
- change у select — обновляет результаты при выборе фильтра.
- submit у формы — preventDefault() не даёт Enter перезагрузить страницу.
- reset — очищает поле, возвращает оба фильтра в all и снова запускает filterItems().
- defer у script — запускает файл после разбора HTML, когда карточки и поля уже доступны.

## Как добавить карточку

Скопируй соседний div с item-card в нужную секцию. Замени индивидуальный класс, название, data-name, цену, картинку, alt и ссылку More. Укажи правильные data-category и data-group. Теги добавь через пробел. Дописывать JavaScript для новой карточки не нужно; после изменения HTML обнови страницу.

## Что проверено

Поиск без учёта регистра и пробелов, одновременное применение категории и тега, отсутствие результатов и скрытие пустых секций, Reset и Enter. Проверено наличие всех локальных ресурсов. Источники и происхождение изображений перечислены в SOURCES.md.

Технические скрипты и резервная копия твоего исходного index.html находятся в work/. Для работы сайта эта папка не нужна. Перезапуск генератора work/build-catalog.cjs перезапишет index.html, поэтому для дальнейшей самостоятельной работы редактируй HTML напрямую, не запускай генератор.
